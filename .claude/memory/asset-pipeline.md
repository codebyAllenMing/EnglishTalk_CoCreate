**2026-08-20 記錄。** 素材由 Allen 這端產出，非夥伴手繪流程。

## 工具分工

| 工具 | 產出 | 實際用在 |
|---|---|---|
| **Codia** | SVG（真向量） | `笑臉.svg` → app icon / favicon 全套的母檔 |
| **ChatGPT** | PNG（點陣） | banner 桌機版與手機版、揮手怪獸 |

## 為什麼要記

**Why:** 兩個工具的產出特性不同，決定了後處理方式與檔案格式判準：

- **Codia SVG** 是描邊產生的真向量（笑臉那張 55 個 path），可任意縮放、可程式化改色 → 適合 icon。
  但描邊向量在「有漸層質感的插圖」上會爆量（實測揮手怪獸 SVG 613KB / 31 色，同圖 WebP 只要 34KB / 48,948 色且更好看）。
- **ChatGPT PNG** 是點陣，帶背景、無 alpha → 一律要去背 + 轉 WebP 才入庫。
- **兩者都會色彩漂移**：同一隻怪獸的主體紫出現過四個值（`#723CFB` / `#5E29EA` / `#7245E1` / `#7C4DEB`）。

**How to apply:**

1. **拿到新素材先問是哪個工具出的** — Codia → 走 SVG 路線；ChatGPT → 走去背 + WebP 路線。
2. **入庫前一律程式化調色**到 palette（見 vault 的 `design-tokens.md` 有 icon 調色映射表），不要肉眼判斷「看起來差不多」。
3. **格式判準**：扁平可縮放的小圖示 → SVG；有漸層質感的插圖 → WebP。
4. **去背背景色的取樣**：不可無腦用四角中位數 — 手機版 banner 構圖是「上方留白、下方場景佔滿」，
   左下會取到沙發、右下取到桌子。須改取上方純色區驗證 std 後再用。

## 一組圖示要「視覺重量」對齊，不是外框對齊

八個圖示各自生成，外框佔比從 31% 到 61% 都有，直接放上去會大小不一。
校正指標：**墨量 = 平均色深 × 著墨像素數**，再開根號換算縮放係數。

⚠️ **純墨量指標在「深色小物 vs 淺色大物」之間會失準** —— 四步驟的日曆主體是白的
（平均深度 78.9，其他三張 163–183），純墨量算法把它放大到畫布 92%，結果它撐爆圓底。
修正：**墨量係數與外框係數取幾何平均**，再加一道外框硬上限。

規格與踩坑細節在 vault 的 `landing-page-spec.md`（入口見 [[englishtalk-vault-pointer]]）；
實作狀態見 [[frontend-build-state]]。

## 兩條處理路線（2026-08-23 補）

`build_icons.py` 現在有兩種群組：

- **要互相對齊份量的**（features / steps / stats / avatars）→ 走 `balance()`
- **各自絕對定位的**（auth）→ 走 `trim()` + `fit()`，不做平衡

判準是「這組圖會不會並排出現、需不需要看起來一樣重」。登入頁那四隻怪獸
散在版面不同角落、尺寸由設計稿決定，硬套 `balance()` 反而錯。

⚠️ `trim()` 的 `alpha_floor` 預設 **8** 不是 0 —— AI 出圖邊緣常有一圈 alpha 1~5 的
雜訊，照 0 去裁會多留十幾 px 空邊，之後絕對定位就對不準。

## ⚠️ cutout() 只能用在「白底」母檔（2026-08-27 踩過）

`cutout()` 第一行就是 `Image.open(path).convert("RGB")` —— **丟掉原有的 alpha**，
接著找「與邊緣相連的白色區塊」當背景。對**已經去背**的透明 PNG 跑它是破壞性的：
透明區轉 RGB 後變成黑色，白色偵測找不到背景，於是 `alpha` 全填 255，
整張圖變成**不透明的黑底**。

⚠️ `balance()` 那條路徑**一律先跑 `cutout()`**。所以已去背的母檔進 balance 群組時，
spec 必須帶 **`cutout: False`**（頭像那 11 張就是這樣）。
走 `build_trimmed` 的群組（auth / profile）不經過 cutout，不受影響 ——
這也是為什麼登入頁的怪獸一直正常、只有頭像出事。

判準：**母檔是白底 → 要 cutout；母檔已透明 → `cutout: False`。**

診斷方式：合成到白底看是不是黑的，或看 alpha 直方圖 ——
被 cutout 毀掉的圖會是「只有 0 與 255、沒有中間值」，
正常的去背圖會有 30% 上下的半透明像素（那是抗鋸齒邊緣）。
