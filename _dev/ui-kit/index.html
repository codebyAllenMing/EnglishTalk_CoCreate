Core

主色與副色

主色的可信度來自收斂：五個彼此獨立的 UI 元件都落在同一個紫，代表它是品牌色， 而不是插圖顏色被平均出來的結果。
#6948DC

Primary · 紫

Sign up 按鈕、Find a conversation、chill. 標題、底部 CTA、Open a time slot——五處量測值 #6540dd ~ #6b4bde。

#359F95

Secondary · 青綠

取自 hero 的「seriously.」標題字。對比度僅 3.21:1，只能用在大字，內文要降到 700 階。

#0D1852

Ink · 文字

取自 Logo 的「ME」字。是很深的藍紫，不是純黑——中性階全部由它衍生，所以不用純灰。

Scales

十階色票

點任一色塊複製色值。50–400 為淡階（用於底色、hover 底），500 為品牌基準，600–900 為深階（用於文字與 hover）。

可讀性限制

這幾條會直接影響實作。三個顏色不能當文字色——違反了就是可讀性缺陷，不是風格問題。

選字體時要一起考慮

  • 中文字重——三個候選都沒有中文字符，中文會 fallback 到系統字體。若 Landing 要做 i18n，中文字體需另外指定（思源黑體 / Noto Sans TC）
  • Fredoka 沒有 800 字重，最粗到 600；Nunito 有 1000
