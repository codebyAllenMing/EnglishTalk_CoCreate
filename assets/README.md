# assets

專案素材。**只放實際用到的**——中間檔（去背、調色的過渡產物）不進版控，跑一次腳本就有。

```
assets/
├── design/     視覺稿與 Logo 稿，開發依據
├── source/     AI 產出母檔，重新處理時的來源
└── tools/      處理腳本
```

正式使用的檔案在 `apps/web/public/images/`，由 `tools/build_icons.py` 產出，**不要手動編輯**。

## 素材怎麼來的

| 工具 | 產出 | 用在 |
|---|---|---|
| **Codia** | SVG（真向量） | app icon / favicon |
| **ChatGPT** | PNG（點陣，帶白底） | banner、八個圖示、揮手怪獸 |

出圖規格：**1:1，1024×1024，物件填滿約 80%、置中，背景純白 `#FFFFFF`，不要投影。**

⚠️ **不要叫 ChatGPT 去背。** 你截圖給它，它是重畫一張而不是真的去背，出來的邊緣會帶一圈半透明白邊，放到米底頁面上會浮出白框。**叫它出乾淨白底，去背用 `iconkit.cutout()` 做**——連通區域分析，只刪與畫布邊緣相連的白，圖形內部的白（眼白、星星、勾勾）完整保留。

⚠️ **顏色一律會漂。** 同一隻怪獸的主體紫出現過四個值（`#723CFB` / `#5E29EA` / `#7245E1` / `#7C4DEB`）；叫它參考另一張圖的質感，它會連顏色一起抄走。**不用在 prompt 上跟它耗**——質感對就收，顏色用 `iconkit.recolor()` 在 HLS 空間位移到 palette，3D 的高光與陰影原封不動。

## 重跑

```bash
python assets/tools/build_icons.py            # 八張圖示全部重產
python assets/tools/build_icons.py features   # 只跑四特色
```

相依：`pillow`、`numpy`、`scipy`。

新增圖示就在 `build_icons.py` 的 `FEATURES` / `STEPS` 加一筆，需要調色的話填 `recolor=dict(...)`。

## 格式判準

**扁平可縮放的小圖示 → SVG；有漸層質感的插圖 → WebP。**

實測依據：揮手怪獸的描邊 SVG 是 613 KB 且只剩 31 色，同一張 WebP 只要 34 KB 卻有 48,948 色。有體積光影的東西轉向量會又肥又失真。

## 一組圖示要對齊「視覺重量」，不是外框

八張圖各自生成，外框佔比從 31% 到 61% 都有，直接放上去大小不一。校正指標是**墨量 = 平均色深 × 著墨像素數**。

⚠️ 純墨量指標在「深色小物 vs 淺色大物」之間會失準——四步驟的日曆主體是白的（平均深度 78.9，其他三張 163–183），純墨量算法把它放大到畫布 92%，撐爆了圓底。`iconkit.balance()` 的 `box_weight` 就是為此存在：外框係數與墨量係數取加權幾何平均，四特色用 0.0（純墨量夠用），四步驟用 0.5。

## 顯示尺寸怎麼定的

視覺稿是 1024 寬，稿上 Features 白卡寬 847px、圖示 56px；實際卡片 `max-w-6xl` = 1152px。**比例 1.36**，所以圖示該是 56 × 1.36 ≈ 76px，取 80px。

四步驟的圖佔圓 71%，與視覺稿一致。
